# 快修24 商業規則

最後更新：2026-08-30

本文件記錄已確認的產品及收費規則。設計資料模型、Stripe 流程、權限及介面時，均以本文件為準。

## 帳戶及付款對象

- 平台採用師傅月費訂閱模式。
- 只有師傅需要提供付款卡；客戶毋須提供信用卡。
- 客戶接受報價及建立訂單，目前不涉及客戶付款。
- 師傅收入、平台代收工程費及向師傅 payout，目前不屬於訂閱功能範圍。
- 完整卡號、CVC 及其他敏感卡資料必須由 Stripe 處理，不得儲存在快修24資料庫或 logs。

## 月費及免費試用

- 每位師傅的月費為港幣 HK$100。
- 每位師傅均享有首 3 個月免費試用期。
- 「3 個月」指香港時間的三個日曆月，而不是固定 90 日；月底日期按目標月份最後一日截算。
- 免費試用期由師傅成功綁定付款卡當日開始計算。
- 綁卡是開始免費試用及啟用師傅訂閱的必要條件。
- 正式環境嘅 SMS／電話驗證功能暫時停用；註冊仍須提供有效香港手提電話，供聯絡、登入及帳戶復原使用。Local 及 Development 連接 DEV DB，由 DEV DB config 控制 console POC；正式環境連接 PROD DB，由 PROD DB config 控制 Twilio Verify，而且 restricted API key 只容許發送驗證碼及核對驗證碼。兩個環境均以各自 DB `feature:smsVerification.enabled` 作唯一推出開關。無論使用邊個 provider，使用者均須在註冊表格先收取及驗證 SMS，最後提交時 server 必須再次確認同一電話已驗證，通過後先可建立帳戶。正式環境 credentials、DB provider 及真人香港電話端到端測試全部完成前，不得啟用 PROD DB 開關。
- 師傅完成註冊後立即進入綁卡流程，不等待管理員審批；帳戶審批與訂閱狀態分開處理。
- 免費試用期間不收月費；試用期完結後改為每月自動收取 HK$100。
- 平台尚未正式上線，因此現有及之後建立的師傅帳戶一律適用相同的 3 個月免費試用規則。
- 每位師傅只可享有一次免費試用；更換付款卡、取消後重開或重新訂閱均不會重設免費期。
- 已用過免費試用的師傅重新訂閱時，不會再有免費期；新一期須按當時固定月費開始收費，成功付款後才恢復新工作權限。
- 師傅訂閱狀態必須與工作訂單、報價及工作狀態分開管理。

## 扣款失敗

- 每月扣款失敗後，師傅最多有 14 日寬限期更新付款方法及完成付款。
- 14 日按第一次扣款失敗起計的 336 小時計算，限期正點即告完結；同一張欠款帳單的重試或重複 webhook 不會延長限期。
- 寬限期內保留原有平台使用權，但介面必須清楚提示欠費、最後處理日期及更新付款卡入口。
- 寬限期完結後仍未成功付款，暫停建立報價及接受新工作。
- 欠費師傅仍可登入、更新付款方法，以及查看和處理寬限期前已存在的工作及紀錄。
- 「既有工作」指暫停前已獲接受及已建立的正式工作；尚未被客戶接受的報價不視為既有工作，暫停後不可由該報價建立新訂單。
- 只更新付款卡不代表欠款已繳清；必須由 Stripe 確認當前欠款帳單成功付款後，訂閱功能才會恢復。
- 成功補交欠款後，自動恢復訂閱功能。

## 取消訂閱及退款

- 師傅可隨時取消訂閱。
- 取消採用期末生效：取消後停止下一期自動續費。
- 如果本期月費已收取，師傅可繼續使用平台至下一個原定收款日之前。
- 已收取的當期月費不作按比例退款。
- 如果師傅在免費試用期內取消，可繼續使用至免費試用期完結，之後不會收取首期月費。
- 欠費期間提出取消只會停止之後續期，不會豁免目前欠款；新工作權限仍按原有寬限期及暫停規則處理。

## 實作要求

- 訂閱狀態至少要能區分：免費試用中、正常生效、寬限期、已取消但仍在有效期、已暫停及已終止。
- 師傅登入權限與付費功能權限分開處理，欠費不應令師傅無法更新付款方法或查看既有工作。
- Stripe webhook 是訂閱付款狀態的主要依據；不能只依賴付款完成頁面或 browser redirect。
- Stripe 付款卡更新頁或帳單頁返回網站只代表流程返回，不等於付款成功；必須以已驗證 webhook 及 Stripe 當前帳單狀態確認。
- Webhook 必須驗證簽名、支援重複事件去重，並安全處理事件延遲及亂序。
- 所有金額以整數最小貨幣單位保存，並同時保存貨幣代碼。
